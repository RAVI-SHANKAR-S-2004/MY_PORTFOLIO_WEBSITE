# Portfolio Website 🚀

A modern and responsive personal portfolio website built using HTML, CSS, and JavaScript. This project showcases my skills, projects, education, certifications, and contact information in a clean and interactive design. 

## ✨ Features

* Responsive modern UI design
* Smooth scrolling navigation
* Interactive project cards
* Animated hero section
* Mobile-friendly layout
* Contact form with WhatsApp integration
* Project showcase with live demo & GitHub links
* Optimized performance and clean code structure

## 🛠️ Technologies Used
